MULTISENSOR AI -- SENSING NODE 0.1.0-bench

INSTALL ON WINDOWS
1. Extract the complete package. Keep release/ beside the installer scripts.
2. Connect normal board power and USB. Close other serial monitors.
3. Double-click Install-Firmware.cmd. No Arduino IDE is needed.
4. Double-click Open-Console.cmd. Type setup and press Enter.
5. Record the unique setup code on the device label. Type status to see its IP.

PREPARE THE RECEIVER
Windows: install Python 3.12, then run receiver/Setup-Receiver.cmd. Enter the
receiver address that the node can reach. Run receiver/Start-Receiver.cmd.
Allow inbound TCP 5443 for this receiver on the test network if the PC firewall
blocks it. For a remote PC behind a router, forward TCP 5443 to that PC.
Use the new receiver in this package, not the previous Home_Receiver scripts.

SET UP THE NODE
1. Join its MSAI-xxxxxx hotspot with its setup code. Open http://192.168.4.1/.
   Alternatively connect Ethernet to a DHCP router, then open the board's IP or
   http://msai-xxxxxx.local/ from a computer on the same network.
2. Enter the setup code. Select Wi-Fi, Ethernet or BLE.
3. Wi-Fi: Scan, choose the network, enter its password and Connect.
   Ethernet: uses DHCP unless you choose static IP settings.
4. Select Local gateway or Cloud/remote (BLE always uses Local base station).
5. Import receiver/identity/connection.json. Check its address and port.
   For BLE choose the rate; 10,000 samples/s needs adapter throughput testing.
6. Save & start. The node saves its settings and restarts. Its setup hotspot
   closes after the receiver authenticates. Subsequent boots reconnect.

BLE RECEIVER
From receiver/, using its Python environment:
  .venv\Scripts\python receiver.py ble --name MSAI-xxxxxx
BLE is local only. The same decoder handles BLE, Wi-Fi and Ethernet data.

RESET SETTINGS
Hold BOOT for 10 seconds after startup, or type reset-setup in Open-Console.cmd.
RESET alone only reboots. Sensor calibration and the device setup code survive.

FIRST TEST
Keep sensor inputs disconnected. CR/30 A should leave all four relays released.
Require receiver STATUS fault=0 and running=true, waveform rate=10000 on Ethernet/
Wi-Fi, and zero discontinuities, overflows, missed_adc and adc_crc during the run.
The board is NOT fully qualified just because it boots or authenticates.
See VALIDATION.txt for completed checks and outstanding hardware tests.

Lossless compression preserves every output sample at the chosen sample rate.
The receiver saves compressed .msac recordings and decodes them for validation.
Use export_recording.py to export exact integer-count CSVs when needed.

DEVELOPERS
Native ESP-IDF 5.5.5, official Espressif tools. See README.txt for build, protocol,
calibration, security model and integration details. The setup HTML is embedded
in firmware and needs no Internet connection or separate web hosting.
